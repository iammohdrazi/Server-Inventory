Engineered for Linux Administrators

Everything you need to monitor, troubleshoot, and administer your fleet without heavy container agents.

🧠

Human-Readable Descriptions

No more guessing cryptic systemd unit names. Every package and service provides a concise, beginner-friendly description of what it does and whether it is safe to restart.

🔒

Native Linux PAM Auth

No separate database or user accounts to sync. Authenticate securely using your existing OS user accounts (PAM) with JWT sessions and rate-limited brute force protection.

🖥️

Full Hardware Telemetry

Deep hardware profiling: CPU architecture, thermal sensors, memory channels, NVMe/SATA SMART health, motherboard BIOS revisions, and PCI hardware inspection.

💻

In-Browser Terminal

Need direct CLI access? Launch a full pseudo-terminal (PTY) inside your browser with xterm.js emulation, ANSI colors, tab completion, and zero external SSH keys required.

📁

Web File Explorer

Browse directories, upload configs, inspect system logs, download backups, and edit files directly through an intuitive web-based file management interface.

🚀

Zero External Dependencies

Installs as a native systemd unit in seconds. Runs on pure Python + gevent with auto-generated 10-year TLS certificates. No Docker required.

Enterprise-Grade Security by Design

ServerInventory is designed to run safely on production systems, isolated internal networks, and bare-metal homelabs alike.

  • ✓ TLS 1.2 & 1.3 Encryption: Auto-generated certificate chains with strong ciphers.
  • ✓ PAM Authentication: Validates passwords against Linux shadow hashes.
  • ✓ Rate Limiting: In-memory brute-force defense on auth endpoints.
  • ✓ Session Timeout: Auto-invalidating JWT tokens with secure cookies.
